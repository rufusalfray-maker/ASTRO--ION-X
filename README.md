# ASTRO--ION-X
A smart lunar safety system that detects and safely manages electrostatic charges on astronauts’ spacesuits using sensors and a specially designed metal sole.
ASTRO-ION X 🚀

Smart Lunar Electrostatic Protection System

ASTRO-ION X is a conceptual safety system designed to detect and safely manage electrostatic charges on astronauts' spacesuits using smart sensors and a specially designed metal sole.

Key Features

- Smart Metal Sole
- Electrostatic Sensors
- Controlled Discharge System
- Astronaut Safety

Project Goal

To improve astronaut safety during future lunar missions.
